# Brainstorm Research Laboratory — Fellows & Contributors Directory

This directory records official fellow profiles, active quest assignments, and verified contributor credentials for the **Brainstorm Research Laboratory (BRL)**.

---

## Contributor Ranks & Progression

Every fellow advances through the rank hierarchy defined in [`PLAN-BRL-001`](../plans/PLAN-BRL-001_BRAINSTORM_RESEARCH_LAB_CHARTER.md):

| Rank | Designation | Primary Focus |
|---|---|---|
| **Rank E** | Research Scout | Baseline reproduction, environment verification, raw data scraping |
| **Rank D** | Research Analyst | Dataset cleaning, failure-mode taxonomy, edge-case probing |
| **Rank C** | Research Engineer | Feature implementation, pipeline adapters, tool integrations |
| **Rank B** | Research Fellow | Formal verification, Z3/SMT proofs, performance benchmarking |
| **Rank A** | Senior Fellow | Architecture design, theoretical proofs, conference authorship |

## Onboarding Procedure

1. Read the [BRL Contributor Agreement](../plans/BRL_CONTRIBUTOR_AGREEMENT.md).
2. Follow instructions in [Quest 0: The Onboarding Litmus Test](../plans/BRL_QUEST_0_DRY_RUN.md).
3. Copy [`TEMPLATE.md`](TEMPLATE.md) to `<your_github_username>.md` in this directory.
4. Fill in all sections, ensure `.\audit.bat` (or `./audit.sh` on Linux/macOS/WSL) passes with 0 discrepancies, and submit your PR (from your contributor branch or personal fork).
