# Calm Authority Vocabulary Cheatsheet

Quick reference for transforming marketing hype and academic hedging into calm, precise engineering prose.

---

## 1. Banned Hype Words & Replacements

| Banned Hype Word | Why It Fails | Calm Authority Replacement |
| :--- | :--- | :--- |
| **Revolutionary / Groundbreaking** | Empty assertion. Let the evidence demonstrate novelty. | *"A tool that..."*, *"A framework for..."*, *"An approach using..."* |
| **Game-changing** | Overused cliché. | State the specific change: *"Reduces audit latency from 45m to 12s"* |
| **Unleash / Supercharge** | Emotional verb implying latent magic. | *"Enables"*, *"Computes"*, *"Runs"*, *"Executes"* |
| **Seamless / Seamlessly** | Almost always a lie in engineering; obscures real integration points. | *"Connects via [API/CLI/Socket]"*, *"Imports from"* |
| **Effortless / Effortlessly** | Erases technical complexity and operational reality. | *"In a single command"*, *"Without manual configuration"* |
| **Paradigm shift** | Academic/marketing melodrama. | *"A change in how [process] operates"* |
| **Next-gen / State-of-the-art** | Deprecates in 6 months; vague without benchmark citations. | *"Evaluated against [Benchmark Name] achieving [Metric Score]"* |
| **Cutting-edge** | Filler adjective. | State the underlying algorithm or method (*"Bootstrap BCa resamples"*) |
| **Magic / Magically** | Antagonistic to engineering rigor. | State the deterministic mechanism. |
| **Thrilled / Excited to announce** | Puts emotional self-congratulation ahead of user value. | *"[Product/Feature] is now generally available"* |

---

## 2. Transforming Hedging & Academic Bloat

| Academic Bloat | Why It Drags | Crisp Claude-Style Directness |
| :--- | :--- | :--- |
| *"In this paper/post, we endeavor to demonstrate..."* | Preamble delay. | State the finding immediately in sentence 1. |
| *"It is important to note that..."* | Meta-commentary. | Delete the phrase; state the note directly. |
| *"We propose a novel methodology for..."* | Defensive self-defense. | *"We built [Tool], which [verifiable action]."* |
| *"Future work could potentially explore..."* | Vague hand-waving. | *"We deferred [Feature]. The current release covers [Scope]."* |
| Semicolon-linked 50-word compound sentences | Reader cognitive overload. | Break into 2-3 short, atomic sentences. |

---

## 3. Honesty & Scope Markers

Use these authentic qualification markers to build immediate reader trust:

- *"answers most inbound customers"* (instead of *"answers all queries"*)
- *"small TypeScript functions"* (instead of *"powerful extensible architecture"*)
- *"now available in early access"* (explicitly marking beta vs GA)
- *"subgroups with n < 30 are suppressed"* (clear scientific boundary)
- *"UTKFace was profiled and cut from implementation scope"* (transparent engineering trade-off)
- *"write one yourself or ask Claude Code to write it"* (neutral about manual vs AI workflows)
