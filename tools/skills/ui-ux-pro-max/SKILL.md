# UI/UX Pro Max Design Intelligence

This skill dictates high-fidelity design standards, component architecture, and aesthetic constraints for all frontend code generated by Antigravity. When designing interfaces, never default to plain or generic boilerplate styles.

---

## 1. Design Tokens & Color Systems

### Dark-Mode First Architecture
- **Base Background**: Deep slate/zinc undertones (`#030712`, `#090d16`, `#0b0f19`) rather than pure `#000000` to prevent stark harshness.
- **Surface Elevation Layers**:
  - `Surface 0 (Canvas)`: `#070b14`
  - `Surface 1 (Cards / Containers)`: `rgba(15, 23, 42, 0.7)` with `backdrop-filter: blur(16px)`
  - `Surface 2 (Elevated / Modals)`: `rgba(30, 41, 59, 0.8)` with `backdrop-filter: blur(20px)`
  - `Surface 3 (Overlays / Menus)`: `rgba(51, 65, 85, 0.85)`
- **Border & Specular Highlights**:
  - Base Border: `rgba(255, 255, 255, 0.08)` or `rgba(148, 163, 184, 0.12)`
  - Hover Highlight: `rgba(99, 102, 241, 0.4)` or `rgba(255, 255, 255, 0.2)`
  - Inner Glow: `inset 0 1px 0 0 rgba(255, 255, 255, 0.08)`

### Brand & Semantic Accents
- **Primary / Brand**: Indigo to Violet gradients (`#6366f1` -> `#8b5cf6`) with glow layers (`box-shadow: 0 0 24px -4px rgba(99, 102, 241, 0.35)`).
- **Pro / Gold Tier**: Warm Amber (`#f59e0b` -> `#fbbf24`) with subtle radiance.
- **Success**: Emerald (`#10b981`), Warning: Amber (`#f59e0b`), Destructive: Rose (`#f43f5e`).
- **Contrast**: Ensure minimum 4.5:1 contrast for normal text and 3:1 for large text / UI elements (WCAG AA).

## 2. Typography Hierarchy & Spacing

### Font Pairings
- **Primary Body & Display**: `Plus Jakarta Sans` or `Inter`, paired with `JetBrains Mono` or `Fira Code` for badges, timestamps, IDs, and metrics.
- **Letter Spacing**:
  - Display / Headings: `-0.025em` to `-0.035em` (`tracking-tight`) for an editorial, modern feel.
  - Subtitles & Overlines: `+0.05em` to `+0.1em` (`tracking-wider` / uppercase) with smaller font sizes (`text-[10px]` to `text-xs`).
  - Monospace Elements: `font-mono` with subtle background pill wrappers.

### 4px / 8px Spacing Grid
- Never use arbitrary disconnected paddings. Stick to the 4px/8px rhythm:
  - Micro: `4px` (`gap-1`), `8px` (`gap-2`)
  - Compact: `12px` (`p-3`), `16px` (`p-4`)
  - Medium: `24px` (`p-6`), `32px` (`p-8`)
  - Macro: `48px` (`py-12`), `64px` (`py-16`)

## 3. Component Construction Standards

1. **Card Architecture**:
   - Header with badge/icon and actions.
   - Clear visual hierarchy with primary label, description, and metadata tags.
   - Clean footer separated by an ultra-fine divider or whitespace.
   - Soft hover lift with spring timing function (`cubic-bezier(0.16, 1, 0.3, 1)`).

2. **Buttons & Interactive Elements**:
   - Subtle top-edge inner highlight (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.15)`).
   - Active press scale: `active:scale-[0.98]` or `active:scale-95`.
   - Distinct disabled states (`opacity-50 pointer-events-none`).

3. **Form Fields & Inputs**:
   - Inset background: `bg-slate-900/90` with fine border `border-slate-700/80`.
   - Focused state: Focus ring with brand glow `focus:ring-2 focus:ring-indigo-500/20 focus:border-indigo-500`.
   - Keyboard hint pills (`kbd`) styled cleanly.

4. **Empty & Loading States**:
   - Never leave empty screens blank. Always provide illustrated empty states with contextual icons, clear explanations, and a primary CTA.
   - Skeletons with gentle shimmer animations instead of jarring layout shifts.
