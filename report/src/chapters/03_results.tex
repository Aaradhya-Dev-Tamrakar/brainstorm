\section{Experimental Methodology (EXP-001 Protocol)}
To evaluate the boundary at which the IPU outperforms conventional host memory architectures, a multi-dimensional parameter sweep was executed modeling varying ingress rates $R_{\text{in}} \in [25, 500]\text{ GB/s}$ and semantic compression ratios $\rho \in [0.001, 0.90]$ across three generations of host interconnects:
\begin{enumerate}
    \item \textbf{PCIe 5.0 x16:} $64\text{ GB/s}$
    \item \textbf{CXL 3.0 / PCIe 6.0 x16:} $128\text{ GB/s}$
    \item \textbf{Next-Gen CXL 4.0:} $256\text{ GB/s}$
\end{enumerate}

\section{Analysis: The Break-Even Frontier}
The results demonstrate that whenever the semantic reduction ratio satisfies $\rho \le 0.50$ (i.e., at least half the incoming raw data represents redundant transmission entropy), the IPU achieves strictly superior end-to-end latency and interconnect energy efficiency. Furthermore, when $R_{\text{in}}$ exceeds host bus capacity, conventional host queues experience catastrophic latency degradation, whereas the IPU maintains bounded processing time.
